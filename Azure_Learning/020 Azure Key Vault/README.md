# 020 Azure Key Vault

## 📌 Overview

Azure Key Vault is a **cloud service for securely storing and managing secrets, keys, and certificates**.  
It enables applications and users to safeguard cryptographic keys and sensitive information, while providing controlled access and logging.  

Key Vault helps with:
- **Secrets Management** → Store connection strings, API keys, passwords.  
- **Key Management** → Manage cryptographic keys for encryption/signing.  
- **Certificate Management** → Secure SSL/TLS certificates lifecycle.  
- **Access Policies & RBAC** → Fine-grained control over usage.
