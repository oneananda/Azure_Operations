# Migrating SQL Server from on-premises to Azure Cloud

This involves several steps to ensure a smooth transition, proper configuration, and optimization of the databases in the cloud.

## Assessment

- Current environment
- Current version
- Size
- Workload
- Performance requirements
- Dependencies
- Type (Standalone, clustered, availablity group)

## Migration tasks

- Use Azure Migrate to assess the on-premises SQL Server environment
- Use Data Migration Assistant (DMA) to check for compatibility issues
- Use Azure Database Migration Service (DMS) to perform the migration
- Use Azure SQL Database Migration Assistant (DMS) to perform the migration
