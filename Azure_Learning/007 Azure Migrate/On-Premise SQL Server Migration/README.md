# Migrating SQL Server from on-premises to Azure Cloud

This involves several steps to ensure a smooth transition, proper configuration, and optimization of the databases in the cloud.

## Assessment

- Current environment
- Current version
- Size
- Workload
- Performance requirements
- Dependencies
- Type (Standalone, clustered, availablity group)

## Planning

- Choose the right Azure SQL service
  - Azure SQL Database 
  - Azure SQL Managed Instance
  - SQL Server on Azure Virtual Machines
